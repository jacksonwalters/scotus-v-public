About this comparison

TF-IDF ranks texts by keyword relevance. Court polarity combines SCDB decision direction with the vote margin. Survey polarity combines saved question orientations with yearly response averages. Lines are descriptive linear fits, not forecasts or causal evidence.

{% if info.get('public_trends_enabled') %}

Public scores use explicit answer mappings from −1 (conservative) to +1 (liberal), exclude missing answers, and use each question’s documented full-sample weight. One variant per question family contributes each year; family scores are averaged equally. Unchanged-policy answers are midpoint scores, not necessarily ideological centrism. Coverage varies by topic and year. Court scoring retains the last matched case per year; the two scales measure different things.

{% else %}

This reconstruction preserves the legacy calculation: unweighted survey category-order scaling (including labeled missing responses), and the last matched Court case per year. These limitations can materially affect results; this is a historical exploratory project, not a validated public-opinion measure.
